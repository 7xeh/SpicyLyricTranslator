# Getting Started

## Requirements

- Spicetify `>= 2.0.0`
- The Spicy Lyrics extension, installed and working
- An internet connection for first-time translations and update checks

## Install

**Marketplace (recommended)**

1. Open the Spicetify Marketplace
2. Search for **Spicy Lyric Translator**
3. Click **Install**

No further setup needed. For loader script or Windows installer instructions, see [Installation](installation.md).

## First run

Out of the box the extension uses **Google Translate**, so it works with no API keys and no configuration.

1. Play a track that has lyrics in Spicy Lyrics
2. Open the lyrics view
3. Click the **translate button** in the lyric view controls

The first translation for a track takes a moment; after that it's cached and reloads instantly.

## Set your target language

1. **Right-click** the translate button to open the quick settings popup
2. Set **Target Language** to whatever you want lyrics translated into
3. Pick a **Translation Display** mode:
   - **Replace** — swaps the original lines for translated lines
   - **Below each line** — keeps the originals and adds translations underneath

Everything else has a sensible default. See [Settings](settings.md) for the full list.

## Translate automatically

Turn on **Auto-Translate on Song Change** and the extension translates each new track as it starts, with no clicking.

## Keyboard shortcut

Press `Alt+T` at any time to toggle translation on and off.

## Where it works

The full lyrics view, the sidebar lyrics view, and picture-in-picture lyrics where available.
